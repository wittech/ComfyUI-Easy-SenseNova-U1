# SenseNova-U1.5 引导式局部编辑融合工作流

本工作流对应 SenseNova-U1.5 官方最佳实践中的三个案例：

- 框选引导的文字风格重塑
- 局部文字替换
- 标记引导的高端复古风格改造

参考：[SenseNova-U1.5 最佳实践（中文）](https://github.com/OpenSenseNova/SenseNova-U1/blob/main/docs/u1.5_best_practices_CN.md)

工作流文件：[`workflows/SenseNova 引导式局部编辑.json`](../workflows/SenseNova%20引导式局部编辑.json)

## 工作流结构

三类任务共用同一套 SenseNova 图像编辑链，只替换整段 Prompt：

```text
Annotation Canvas → Conditioning.Image-1
完整 Prompt 模板 ────────→ Conditioning.prompt

Conditioning 三路条件 → SenseNova Dual Guider → SamplerCustomAdvanced
SenseNova Loader.VAE ─────────────────────────→ VAE Decode → Save Image
```

`SenseNova Annotation Canvas` 自己完成图片上传和标注。它输出的是已经把框线、箭头、文字和涂画栅格化进去的完整图片。SenseNova 看到的是一张带视觉标记的 `Image-1`，没有额外 bbox、mask 或第二个图像参数。

## 绘图节点

`SenseNova Annotation Canvas` 是本仓库内置节点，不依赖其他自定义节点包。它针对官方三个引导编辑案例提供以下操作：

- 矩形定位框：对应官方红框文字风格重塑
- 椭圆/圆圈、箭头和自由画笔：对应多对象标记引导
- 文字说明：可在箭头旁写每个对象的改造要求
- 颜色、线宽、透明度和实线/虚线
- 25%–200% 画布缩放，便于精确框选小文字
- 选择、移动和右下角缩放标注
- 撤销、重做、删除选中标注和清空全部标注

标注以可编辑的矢量对象保存在工作流中，同时生成与原图同尺寸的透明 PNG 覆盖层。执行时后端会先核对图片名称和尺寸，再把覆盖层与原图合成，因此不会把旧图片的标记误套到新图片上。选择工具的蓝色虚线和缩放手柄仅用于界面编辑，不会写入输出图像。

## 怎么在节点内画框和标注

1. 在 `SenseNova Annotation Canvas` 顶部点击上传按钮选择图片；图片会立即显示，无需先运行一次工作流。
2. 选择 `矩形`、`椭圆`、`箭头` 或 `画笔`，设置颜色、线宽、透明度和虚线，再直接拖动画布。
3. 添加文字时，先填写工具栏里的完整说明，可选择无衬线、手写/楷体或衬线/宋体与字号，然后选 `文字` 并点击放置位置。文字框支持换行。
4. 修改已有标注时选择 `选择`：拖动对象可移动，拖动蓝色选择框右下角可缩放，双击文字可回到文字输入框编辑。
5. 编辑下方已经连接的完整 Prompt，把所有 `【填写……】` 占位内容替换掉，然后运行工作流。

键盘快捷键：`V` 选择、`R` 矩形、`E` 椭圆、`A` 箭头、`B` 画笔、`T` 文字；`Delete` 删除选中项，`Ctrl/Cmd+Z` 撤销，`Ctrl/Cmd+Shift+Z` 或 `Ctrl/Cmd+Y` 重做。

拖动矩形或椭圆时按住 `Shift` 可约束为正方形或正圆；拖动箭头时按住 `Shift` 可吸附到 45° 方向。

建议使用醒目且能在提示词中准确称呼的颜色，并尽量少遮挡原图。文字风格重塑通常只需一条红色矩形框；复杂场景可让不同对象使用不同颜色的框、圆圈和箭头，并在旁边放置简短文字说明。

局部文字替换的官方案例只通过“左下角深蓝色矩形信息栏”做语义定位，不强制添加标记。如果目标区域描述足够唯一，可上传图片后不画任何内容，节点会原样输出图片。

节点只处理一张主编辑图，并输出一个 `IMAGE`。其他参考图片仍可分别用 `Load Image` 接到 `Conditioning.Image-2` 至 `Image-10`，不会与主图串联或拼接。

## 三段完整提示词

工作流右侧放置了三个 `PrimitiveStringMultiline` 节点，每个节点都显示一整段完整提示词，不再拆成多个字段：

1. `提示词模板 1｜框选文字风格重塑（已连接）`
2. `提示词模板 2｜局部文字替换（备用）`
3. `提示词模板 3｜标记引导高端复古改造（备用）`

第一段默认连接到 `SenseNova Conditioning.prompt`。使用其他类型时，断开第一段的连线，把第二段或第三段节点的 `STRING` 输出接到 `Conditioning.prompt`。

每段 Prompt 都已经包含完整约束：定位方式、需要填写的内容、保持范围、排版或场景一致性，以及最终删除框线、箭头、涂画和说明文字。用户只需要替换 `【填写……】` 中的内容，其余句子可以直接保留。

### 模板 1：框选文字风格重塑

需要填写：框线颜色、目标文字区域、必须保持的完整文字、目标文字风格、不得变化的其他元素。必须按原版换行填写文字，这会帮助模型保持行数和版式。

### 模板 2：局部文字替换

需要填写：目标区域描述、完整原文、完整新文、不得变化的其他元素。原文和新文都要按照希望得到的行结构换行。官方案例本身没有框线，只通过“左下角深蓝色矩形信息栏”定位；如果区域容易描述，可以不画框。

### 模板 3：标记引导高端复古改造

需要填写：每一处标记对应的修改要求、整体风格目标、不得变化的场景和对象。多处修改建议按“标记颜色／位置：原对象改成什么”逐行填写，以便模型逐项对应。

## 采样设置

工作流保留官方图像编辑默认值：

- Euler
- 50 steps
- timestep shift 3
- text CFG 4
- image CFG 1
- cfg norm `none`

为优先保证精确文字和局部保持，没有连接 8-step LoRA。

默认 latent 为适合竖版文字案例的 `1376 × 2048`。切换到横版场景改造时，可以改为 `2048 × 1152`；其他图片应尽量保持输入宽高比，并让宽高为 32 的倍数。

## 常见问题

- 上传后没显示图片：确认图片已出现在 ComfyUI 的 `input` 目录，重新在节点图片下拉框选择一次；不需要先运行工作流。
- 切换图片后标注消失：这是安全行为。标注绑定原图名称和尺寸，换图会自动清空，避免旧标记覆盖新图。
- 文字大小不合适：先用 `选择` 点中文字，再修改字号；也可以拖动蓝色选择框右下角整体缩放。
- 精细区域难以框选：把画布缩放提高到 150% 或 200%，下方区域可滚动查看。
- 标记残留：在完整 Prompt 中把具体颜色和位置写清楚，并再次强调最终图不得保留这些标记。
- 未标记区域变化过大：在 Prompt 最后一处占位中明确列出必须保持不变的对象、构图、背景、光照和其他文字。
